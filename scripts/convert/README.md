# Скрипт перекодировки видео

Этот скрипт предназначен для пакетной перекодировки видеофайлов в папке `data/videos` с использованием `ffmpeg`.

## Основные возможности
- Поддержка кодеков **H.265 (HEVC)** и **H.264 (AVC)**.
- Автоматический поиск файлов с расширениями: `.mp4`, `.mkv`, `.mov`, `.avi`, `.ts`.
- **Перемещение результатов**: По умолчанию скрипт берет видео из текущей папки (`convert/`) и сохраняет результат в родительскую папку (`data/videos/`).
- **Удаление исходников**: После успешной перекодировки исходный файл в папке `convert/` удаляется.
- Копирование аудио без потери качества.

## Требования
Для работы скрипта должен быть установлен `ffmpeg`.

## Использование

### 1. Подготовка
Положите видео, которые нужно обработать, в папку `data/videos/convert/`.

```bash
cd data/videos/convert
```

### 2. Запустите перекодировку

**В формат H.265 (HEVC):**
Возьмет видео из `convert/`, перекодирует и положит в `data/videos/`.
```bash
python3 transcode_videos.py
```

**В формат H.264 (AVC):**
```bash
python3 transcode_videos.py --codec libx264
```

## Параметры скрипта
- `--path`: Папка с исходными видео. По умолчанию `.` (текущая директория).
- `--out`: Папка для сохранения результатов. По умолчанию `..` (папка выше).
- `--codec`: Выбор кодека (`libx265` или `libx264`).

## Настройки ffmpeg
- **CRF**: 28 для H.265, 23 для H.264.
- **Preset**: `medium`.
- **Audio**: `-c:a copy`.
