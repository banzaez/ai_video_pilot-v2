# Карта помещения

По умолчанию план — **procedural-сетка 0.5 м** (не картинка):
- размер **4800×3200**
- клетка **0.5 м = 80 px**
- пол ≈ **28.5 × 18.5 м**
- клики **snap** к пересечениям сетки

Опционально можно положить свой `floorplan.png` / `.jpg` и выбрать в админке.

## Калибровка `cameras/{id}.json`

Вкладка **Карта**:

1. **1 · Пары H** — точка на кадре → на **пересечении** сетки; тяните точки чтобы править.
2. **4 · Камера** — позиция на пересечении + направление взгляда.
3. Сохранить → `data/maps/cameras/{id}.json` (`floorplan: "grid"`).

`yaw_deg`: 0 = вправо, 90 = вниз.

## Прилавки `counters.json`

Режим **6 · Прилавки**:

1. Клики по **плану** или **кадру** (≥3 вершины).
2. Enter / «Замкнуть → план» — полигон на план (с кадра через H).
3. Сохранить → `data/maps/counters.json`.

```json
{
  "floorplan": "grid",
  "map_size": [4800, 3200],
  "counters": [
    {
      "id": "c1",
      "name": "Прилавок 1",
      "map": [[x, y], "..."],
      "image_by_camera": { "01": [[x, y], "..."] }
    }
  ]
}
```

## Ноги на плане

Точка человека на карте — **низ bbox**. Если низ bbox попадает в зону прилавка на кадре, точка не рисуется.

Поле `body_calib` в `cameras/{id}.json` больше не пересчитывается: стадия pose удалена.
